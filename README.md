# 🎓 Algoritmos e Programação com Python

Bem-vindo ao meu repositório de estudos de Python voltado para o ambiente universitário! Este espaço foi criado para centralizar todos os exercícios, projetos, notas de aula e desafios práticos desenvolvidos ao longo do curso.

---

## 🚀 Objetivo do Repositório

O propósito deste repositório é documentar a minha evolução na linguagem Python, consolidar os conceitos aprendidos em sala de aula e servir como material de consulta rápida para exames e projetos futuros.

---

## 📂 Estrutura do Repositório

O repositório está organizado por tópicos e semanas de aula para facilitar a navegação:

* **`01_introducao/`**: Conceitos básicos, entrada/saída de dados (`input` e `print`) e operadores matemáticos.
* **`02_estruturas_condicionais/`**: Uso de `if`, `elif` e `else`.
* **`03_estruturas_repeticao/`**: Laços de repetição `while` e `for`.
* **`04_estruturas_dados/`**: Trabalhando com Listas, Tuplas, Dicionários e Conjuntos.
* **`05_funcoes/`**: Modularização de código, escopo de variáveis e funções nativas.
* **`projetos/`**: Trabalhos acadêmicos mais complexos e projetos em grupo.

---
